# 전력안심망 시제품

정전 때 재택 생명유지장치(인공호흡기, 산소발생기 등) 사용 가구의 기기 버팀 시간을 계산하고,
지자체 담당자가 비상전원 배정 순서를 정하도록 돕는 웹 시제품.

## 화면
- index.html : 운영자 정전 대응 현황 (판정 묶음, 배정, 승인)
- map.html : 운영자 지도 · 자원대장
- register.html : 보호자 기기 등록 (라벨 사진 글자 인식 또는 목록 선택)
- card.html : 보호자 정전 대비 카드 (인쇄용)

## 실행
서버 없이 동작하는 정적 사이트. 라벨 글자 인식은 웹 주소로 열어야 동작함(파일로 바로 열면 목록 선택만 가능).

    python3 -m http.server 8765

## 데이터
- 가구·자원 위치는 모두 가상 데이터임
- 기기 사양: 제조사 사용설명서 공개본
- 시군구별 생명유지장치 가구 수: 한국전력공사 복지할인대상(공공데이터포털 15039293), 2026년 1월
- 지도: OpenStreetMap 기여자, Esri

## 사용 라이브러리
KRDS 1.1.0, Leaflet 1.9.4, Tesseract.js 5.1.1 (각 vendor 폴더의 출처 참고)
